Why NetScan Pro
Everything a field engineer needs
Built for people who visit different industrial sites daily and need instant network visibility.
⚡
Fast Parallel Scanning
Scans 254 IPs in under 30 seconds using multithreaded ping + ARP + TCP probing simultaneously.
🔍
MAC Vendor Identification
Built-in OUI database covers Siemens, Schneider, Rockwell, Hikvision, Dahua, Axis, Cisco, Mikrotik and more.
🏭
Industrial Protocol Detection
Probes Modbus/502, S7comm/102, EtherNet-IP/44818, OPC-UA/4840, RTSP/554 and 6 more automatically.
📋
Export to CSV
One click exports IP, MAC, hostname, vendor, type and ports to CSV — perfect for site documentation.
🌐
Beautiful Web UI
Opens in your browser. Card grid + table view. Real-time results as devices are found. Dark-mode only.
🐍
Zero Dependencies
Pure Python 3 standard library — no pip install, no nmap, no scapy. If Python runs, this runs.
Quickstart
Up and running in 60 seconds
1
Download the files
Download the ZIP from GitHub. Extract all 4 files into one folder on your laptop.
2
Connect to the site network
Plug into Ethernet or join WiFi at the client site. No other setup needed.
3
Run the scanner
Windows: double-click START_SCANNER.bat  ·  Linux/Mac:
$ python3 network_scanner_server.py
4
Open the portal and scan
Browser opens automatically at http://localhost:8765. Select your interface, click ▶ Start Scan. Devices appear in real time.
5
Export and document
Filter by device type. Click any IP to copy. Export full results as CSV for your site records.
Device Detection
Identifies all your field devices
Automatically classifies devices by MAC OUI database, open protocol ports, and hostname patterns.
